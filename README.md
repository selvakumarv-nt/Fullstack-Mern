▶️ How to Run
For HTML, CSS, and JavaScript files
Clone the repository:
bash
   git clone https://github.com/selvakumarv-nt/Fullstack-Mern.git
Open the folder:
bash
   cd Fullstack-Mern
Open any .html file in your browser (or use the Live Server extension in VS Code).
For React projects
Go into the React project folder:
bash
   cd <project-folder-name>
Install the packages:
bash
   npm install
Start the project:
bash
   npm run dev

(If your project uses Create React App, use npm start instead.)

You need Node.js installed on your computer.
